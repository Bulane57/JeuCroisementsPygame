# 🎮 JeuCroisementsPygame

Un jeu d'arcade 2D développé en Python avec la bibliothèque **Pygame**.

Le but du jeu est de faire croiser deux barres de déplacement au-dessus d'un carré téléporteur afin de réussir 5 croisements le plus rapidement possible et avec le moins de mouvements possible.


## 📌 Aperçu du jeu

* **Interface :** Une zone de jeu principale (gauche) et un panneau de statistiques en temps réel (droite).
* **Mécaniques :**
  * Déplacement continu de deux barres (une verticale et une horizontale).
  * Détection de collision simultanée entre les deux barres et le carré téléporteur.
  * Effets sonores lors de la téléportation.
  * Chronomètre, compteur de mouvements et gestion des records personnels.
 

## 🎵 Crédits / Remerciements
